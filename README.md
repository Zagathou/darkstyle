# DARKSTYLE – Christians Dark Style

Live: **https://zagathou.github.io/darkstyle/**

Stilseite von Christian Grigoriadis (Zagathou / Zagato) zu seinem Dark Style: **Gothic, Bondage-Fashion, Lack & Leder, Schwerter und Accessoires**. Deutsch, Schweizer Rechtschreibung (immer "ss", kein Eszett). Reine Mode- und Stilseite, jugendfrei (keine sexuellen Inhalte, keine Nacktheit); Bondage-Fashion nur als Mode und Ästhetik (Harness, Halsband, Riemen, Schnallen).

## Bilder später einsetzen

Alle Bildrahmen sind im Format **9:16** (empfohlen 1080×1920 px, JPG) und zeigen bis dahin den Platzhalter **"BILD FOLGT"**. Es genügt, das Foto mit exakt diesem Dateinamen ins Hauptverzeichnis des Repos zu legen (gleiche Ebene wie `index.html`) – es ersetzt den Platzhalter automatisch (per CSS, ohne Änderung an `index.html`):

| Bereich | Dateiname |
|---|---|
| Headerbild (oben) | `header.jpg` |
| Gothic | `gothic.jpg` |

| Lack & Leder | `lack-leder.jpg` |

Dateinamen in Kleinbuchstaben, Endung `.jpg` (nicht `.jpeg`/`.JPG`) – GitHub Pages unterscheidet Gross- und Kleinschreibung. Der Bildausschnitt wird mittig (leicht nach oben versetzt) auf 9:16 zugeschnitten. Nur eigene Fotos verwenden, jugendfrei.
